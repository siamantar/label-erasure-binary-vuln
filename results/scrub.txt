SCRUB replaces a token with SYM when it is a C++ mangled symbol
(_Z, __Z, j___Z), or carries 'bad'/'good'/CWE<digits> in a symbol
name, or is test-harness scaffolding. The bad/good test applies to
every token position, not only call targets, because operand names
such as [rbp+dataBadBuffer] leak the label too. Pure numeric and
hex immediates are guarded so a constant like 0BADh is preserved.
MASK additionally replaces recognized C library names with LIBFN.
